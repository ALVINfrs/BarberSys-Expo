# Fase 6 — Simulasi QRIS Dummy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menambahkan alur pembayaran QRIS dummy end-to-end: Kasir menampilkan QR, Customer memindai dengan kamera, ringkasan tagihan, lalu status antrian berubah menjadi `lunas` dan layar Kasir mendeteksi lewat Realtime.

**Architecture:** Payload QR adalah JSON tervalidasi (`queueId`, `total`, `kodeTransaksi`, `timestamp`) di `src/lib/qris.ts`. Kasir menampilkan QR dan subscribe ke baris `queue`; Customer memindai, memverifikasi kepemilikan & total, lalu melakukan satu update `selesai → lunas`. Trigger `queue_guard_update` diperluas agar hanya transisi QRIS itu yang diizinkan untuk customer.

**Tech Stack:** Expo SDK 57, expo-camera, react-native-qrcode-svg + react-native-svg, Supabase Realtime, TypeScript strict.

**Spec:** `docs/prd .md` §13.4 (F6.1–F6.5) + §7 (skema/RLS).

## Global Constraints

- QRIS ini **dummy**: tidak ada gateway finansial nyata.
- Hanya customer pemilik baris `queue` yang boleh membayar; baris walk-in (`user_id = null`) tidak bisa dipindai.
- Transisi yang diizinkan hanya `selesai → lunas`, metode `qris`, `completed_at = now()`.
- QR berlaku 30 menit; QR kedaluwarsa harus ditolak dengan pesan jelas.
- Realtime harus punya fallback polling agar UI tidak menggantung saat koneksi putus.
- Tidak mengubah alur Tunai yang sudah ada.
- Commit hanya atas perintah eksplisit user (AGENTS §6).

## Review Focus

- **QR kedaluwarsa:** customer memindai QR lama → harus ditolak, bukan membayar.
- **QR milik orang lain / walk-in:** customer tidak boleh melunasi antrian orang lain atau baris tanpa pemilik.
- **Total tidak cocok:** tip/produk berubah setelah QR dibuat → customer harus menolak dan meminta QR baru.
- **Realtime putus:** layar Kasir harus tetap mendeteksi `lunas` lewat polling 5 detik.
- **Dobel bayar / race:** dua tap "Bayar Sekarang" atau kasir menutup modal di tengah proses tidak boleh membuat status aneh.

```ts
export const QRIS_QR_MAX_AGE_MS = 30 * 60 * 1000;
export interface QrisPayload {
  queueId: string;
  total: number;
  kodeTransaksi: string;
  timestamp: number;
}
export function kodeTransaksiFromId(id: string): string;
export function computeQueueTotal(
  treatmentHarga: number | null | undefined,
  products: Array<{ subtotal: number }>,
  tip: number
): number;
export function buildQrisPayload(input: {
  queueId: string;
  total: number;
  kodeTransaksi: string;
  timestamp?: number;
}): QrisPayload;
export function encodeQrisPayload(payload: QrisPayload): string;
export type QrisParseResult =
  | { ok: true; payload: QrisPayload }
  | { ok: false; code: 'format' | 'fields' | 'expired'; message: string };
export function parseQrisPayload(raw: string, now?: number): QrisParseResult;
```

### Task 3: Migrasi guard customer `selesai → lunas`

**Files:**
- Modify (via Supabase MCP): function `public.queue_guard_update`
- Modify: `docs/prd .md` (catatan implementasi bila perlu)

**Interfaces:**
- Customer pemilik baris boleh `UPDATE queue SET status='lunas', metode_bayar='qris', completed_at=now()` hanya dari status `selesai`.
- Field lain tidak boleh berubah dalam transisi itu.
- `completed_at` dipaksa `now()` oleh trigger.

- [ ] **Step 1: Terapkan migrasi via Supabase MCP**

Gunakan `apply_migration` dengan nama `fase6_qris_customer_pay` dan SQL berikut (ganti seluruh function, pertahankan cabang barber & kasir):

```sql
create or replace function public.queue_guard_update()
returns trigger
language plpgsql
security definer
set search_path to 'public'
as $function$
begin
  if auth.uid() is null or public.is_kasir_or_admin() then
    return new;
  end if;

  if old.barber_id = auth.uid() then
    if (new.id, new.user_id, new.barber_id, new.treatment_id, new.kursi_nomor,
        new.tip_amount, new.hold_until, new.kasir_id, new.metode_bayar,
        new.completed_at, new.rating, new.komentar, new.nama_customer,
        new.instruksi_potongan)
       is distinct from
       (old.id, old.user_id, old.barber_id, old.treatment_id, old.kursi_nomor,
        old.tip_amount, old.hold_until, old.kasir_id, old.metode_bayar,
        old.completed_at, old.rating, old.komentar, old.nama_customer,
        old.instruksi_potongan)
    then
      raise exception 'Barber hanya boleh mengubah status antrian';
    end if;
    if new.status is not distinct from old.status then
      return new;
    end if;
    if new.status not in ('dilayani', 'selesai') then
      raise exception 'Barber hanya boleh mengubah status menjadi dilayani/selesai';
    end if;
    return new;
  end if;

  -- Customer: pembayaran QRIS (selesai -> lunas)
  if old.status = 'selesai' and new.status = 'lunas' then
    if new.metode_bayar is distinct from 'qris' then
      raise exception 'Pembayaran QRIS wajib memakai metode qris';
    end if;
    if (new.id, new.user_id, new.barber_id, new.treatment_id, new.kursi_nomor,
        new.tip_amount, new.hold_until, new.kasir_id, new.nama_customer,
        new.instruksi_potongan, new.rating, new.komentar)
       is distinct from
       (old.id, old.user_id, old.barber_id, old.treatment_id, old.kursi_nomor,
        old.tip_amount, old.hold_until, old.kasir_id, old.nama_customer,
        old.instruksi_potongan, old.rating, old.komentar)
    then
      raise exception 'Pembayaran QRIS hanya boleh mengubah status, metode, dan waktu bayar';
    end if;
    new.completed_at := now();
    return new;
  end if;

  -- Customer: hanya boleh membatalkan atau memberi rating.
  if new.status is distinct from old.status and new.status <> 'dibatalkan' then
    raise exception 'Customer hanya boleh membatalkan antrian';
  end if;
  if (new.id, new.user_id, new.barber_id, new.treatment_id, new.kursi_nomor,
      new.tip_amount, new.hold_until, new.kasir_id, new.metode_bayar,
      new.completed_at, new.nama_customer, new.instruksi_potongan)
     is distinct from
     (old.id, old.user_id, old.barber_id, old.treatment_id, old.kursi_nomor,
      old.tip_amount, old.hold_until, old.kasir_id, old.metode_bayar,
      old.completed_at, old.nama_customer, old.instruksi_potongan)
  then
    raise exception 'Perubahan field antrian ini tidak diizinkan untuk customer';
  end if;
  return new;
end;
$function$;
```

- Subscribe:
```ts
supabase.channel(`qris-${item.id}`)
  .on('postgres_changes', { event: 'UPDATE', schema: 'public', table: 'queue', filter: `id=eq.${item.id}` }, (payload) => {
    if ((payload.new as any).status === 'lunas') markQrisPaid();
  })
  .subscribe();
```
- Polling fallback 5 detik: `select('status').eq('id', item.id).single()`; jika `lunas`, `markQrisPaid()`.
